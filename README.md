# 童趣 · 学习守护（TongQu AntiAddiction）

一款面向**家庭自用**的 Android 防沉迷学习应用：亮屏累计达到家长设定的间隔后，全屏弹出知识问答，答对才能继续使用手机；孩子通过答题赚取积分、点亮徽章，错题自动归档，把屏幕时间变成学习时间。

## 功能总览

| 模块 | 说明 |
|---|---|
| 定时出题 | 亮屏累计到间隔（1–60 分钟，家长可调）弹出全屏答题悬浮窗；通话中绝不弹出（含微信语音/视频等 VoIP）；答对恢复使用 |
| 答题规则 | 每题 3 次机会；第 1 题全错追加第 2 题（30s 审题）、第 2 题全错追加第 3 题（60s 审题）；连续 5 轮全错锁定 10 分钟 |
| 积分勋章 | 选择题答对 +1、填空题 +2；同一题最多拿 2 次答对加分（之后答对 +0）；答错按本题累计错误次数递增扣分（-1 / -2 / -5 / -10）；连对统计；12 枚勋章自动颁发 |
| 主动答题 | 孩子可从"成长乐园"自愿进入练习模式（10 题/轮），同样计积分，与强制弹窗完全解耦；已出题目不可跳过，退出重进保持原题 |
| 错题本 | 填空题答错自动归档（按内容+年级去重），按科目分类（语文/数学/英语/科学/道法 + 常识） |
| 成长乐园 | 分页展示：成长概况 / 徽章 / 积分等级 / 错题本；昵称可自定义 |
| 拍照录题 | 成长乐园首页一键进入：拍照 → 拖动裁剪框精确框选题目 → AI 视觉模型识别 → 一律转成填空题入库 |
| 家长控制台 | 出题间隔、年级题库选择、前台例外应用白名单（最多 10 个）、题库服务器地址、AI 判题配置、权限引导、真机锁屏（设备管理员） |
| 数据备份 | 家长密码保护；备份以孩子昵称命名（JSON），可上传题库服务器，更换设备一键导入 |
| 题库更新 | 服务器 JSON 下载 + 本地目录导入（JSON / **Excel 另存 CSV**） |

## 使用方法

### 家长（首次安装）
1. 打开应用，按引导授予：悬浮窗权限、电池优化白名单、自启动（EMUI：手机管家允许自启动与后台活动）、通知权限（Android 13+）。

3. **家长控制台**（需密码）可配置：出题间隔、年级、例外应用、题库服务器地址。
4. **家长密码**（两套，注意保管）：
   - 日期倒写：当天 MMDD 倒序（11 月 8 日 → `8011`）；
   - 万能密码：构建期注入（见 `local.properties`），未配置则只有日期口令可用。

### 孩子
- 弹窗答题：答对即解锁手机继续使用；答错按规则追加题目。
- 成长乐园：查看积分/徽章/错题本；点横幅设置昵称；「主动答题」自愿练习赚积分。

1. 旧手机：设置 → 用户数据备份 → **备份到题库服务器**（或本地复制 `Android/data/com.antidip/files/backup/`）。
2. 新手机：设置同一台题库服务器 → 用户数据备份 → **从服务器导入** → 输入昵称即可恢复积分/徽章/错题本。

## AI 判题（硅基流动）

填空题的答案往往"对但写法不同"（如 `0.5` 与 `1/2`、`books` 与中文表达），纯字面比对会误判。开启 **AI 判题** 后，这类答案由大模型判断语义是否等价；**开放式题库**（无标准答案的题目）则完全由 AI 判分——AI 未配置时开放题自动屏蔽，不影响其他题目。

**判分规则：**

- 填空题：字面与标准答案不一致时才询问 AI，语义等价判对；
- 开放式题库：回答切题、合理、无知识性错误即判对；
- AI 网络异常时按原字面判分（fail-closed），绝不会因 AI 故障而误加分；
- 仅填空/开放题触发 AI，选择题仍走本地精确比对，几乎不产生费用。

**开放式题库制作**：在导入目录放 `grade-N-open.csv`（每行一条题干，可选第二列科目），即可让该年级出开放题。示例文件见 `docs/题库/`。

## 拍照录题

把教材/试卷上的题目拍下来，裁剪框选后由 AI 识别，**一律转成填空题**录入题库。
入口：**成长乐园首页 → 📷 拍照录题**。

1. 点「📷 拍照」拍一张清晰的题目照片（调用系统相机，无需额外授权）。
2. **拖动裁剪框**（四角圆点缩放、框内拖动平移）精确框住要录入的题目——框选越准，
   识别越精确；点「✅ 确认裁剪」（「✂️ 重新裁剪」可随时回到原图重框）。
3. 点「🤖 AI 识别题目」：识别结果自动回填科目/题干/答案；**识别出的选择题会把
   正确选项的文字自动转换成填空答案**。未配置视觉模型或识别失败时，直接手动填写即可。
4. 点「保存到题库（填空题）」（年级取控制台当前所选年级；按「题干+年级」自动去重）。

> 提示：需要先在家长控制台「AI 判题」里填入 API Key（端点与视觉模型已预填硅基
> 流动推荐值）。`Qwen3-VL` 系列对中文题目照片效果较好；该模型按量计费，请留意额度。

## 题库建设

### JSON 格式（服务器下发 / 本地导入）
```json
{
  "grade": 4,
  "version": "2026.12",
  "questions": [
    { "subject": "math", "grade": 4, "type": "choice",
      "content": "0.25 等于下列哪个分数？",
      "options": "1/4|1/5|2/5|1/2", "answer": "A", "difficulty": 1 },
    { "subject": "math", "grade": 4, "type": "fill",
      "content": "7/8 - 3/8 = ____（用最简分数表示）",
      "answer": "1/2", "difficulty": 1 }
  ]
}
```
- `subject`：`chinese`/`math`/`english`/`science`/`moral`（其它值按"常识"归类）。
- 同一题跨年级须各自带 `grade`（唯一索引为 `(content, grade)`）。

### Excel 制作（CSV 导入，文件名以年级命名）
1. 用 Excel 编辑，每行一题；另存为 **CSV UTF-8**，命名 `grade-4.csv`（1–6 年级）。
2. 列格式（表头自动跳过，`#` 开头为注释）：
   - 填空题：`题干,答案`
   - 选择题：`题干,选项A,选项B,选项C,选项D,答案`（答案可用 `A`–`D` 或直接写选项文字）
3. 放进手机 `Android/data/com.antidip/files/AntiAddiction/questions/`，点设置页"导入本地题库"或重启应用自动导入；导入成功的文件自动移入 `.processed/`。

## 网络题库服务器搭建

只读服务器（局域网手机可下载题库/备份）：
```bash
python -m http.server 8080 --bind 0.0.0.0 --directory "你的题库目录"
```
手机设置页题库地址填 `http://<PC局域网IP>:8080/questions.json`。

如需支持**从手机上传备份**（`{昵称}.json`），用支持 PUT 的服务器：
```bash
python docs/server_put_server.py 8080 你的题库目录
```
（普通 `python -m http.server` 会忽略 PUT——备份仍保存在手机本地，可手动复制到服务器目录。）

> 安全提示：明文 HTTP 仅适合**自己控制的局域网**。应用内置传输策略：明文 HTTP 只允许私网/本机地址，公网地址必须 HTTPS；公网部署请配置 TLS 并收紧 `network_security_config.xml`。

## 已知能力边界

- 非 Device Owner 时屏幕固定会出现系统"屏幕已固定"确认框（可被取消）；设备管理员 lockNow 需家长在设置页手动启用。
- 华为等 ROM 的后台启动管控：本应用以悬浮窗呈现答题窗（不受后台启动限制）；悬浮窗权限被撤销时回退到 Activity 方式（可能被 ROM 拦截）。
- 内置题库随仓库附带四年级样例库，其余年级通过服务器/CSV 扩展。
