## 一、主动答题（新功能）
- 新增 `ui/PracticeActivity`：孩子从成长乐园自愿进入，10 题/轮的练习模式。

### 一、积分扣减
- **ProgressStore.deductPoints(amount, type, reason)**：积分减至不为负（实际扣减=min(数值,当前)）；连对/最高连对/已得勋章不受影响；每次扣减写记录 `ts|实际扣减|用途|原因`（DataStore，上限 50 条，新→旧展示最近 3 条于设置页积分管理卡）。
- **独立扣减密码 DeductionAuth**：与家长全局密码相互独立；prefs 仅存 SHA-256 哈希；设置≥4 位；扣减操作**只认扣减密码**（全局密码含日期派生，孩子可知日期，故不作为扣减凭证）。
- **修改授权（防遗忘，用户要求）**：设置/重置对话框的授权位 = 旧扣减密码 **或** 家长全局密码（ParentAuth.verify）；首次设置由全局密码授权。
- **设置页「💰 积分管理」卡**：当前积分、最近 3 条扣减记录、"积分兑换/扣减"按钮（对话框：分值 1–999、用途单选 物品兑换/手动扣减、原因可选、扣减密码）、"设置扣减密码"按钮。
