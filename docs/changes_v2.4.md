## 一、错题本"每科只显示一条"修复（根因复盘）

用户报障：错题徽章显示 41，但列表每科只显示一条。排查过程：

1. 拉取设备 `quiz_progress.preferences_pb` 逐字节解析 → **41 条数据完好**（40 个
   记录分隔符，题干完整），排除数据丢失；
2. 设备日志证明 `book=41 filtered=41`、渲染循环执行 41 次 `addView`、
   `wrap.childCount=41` → 排除数据/过滤/渲染中断；
3. **根因**：错题卡 `item` 的高度用了 `MATCH_PARENT`，而外层行容器 `row` 是
   `WRAP_CONTENT` 高——HORIZONTAL LinearLayout 在父高度未定时对 MATCH_PARENT
   高子项测量塌陷，41 行全部高度异常，仅首行可见、滚动无内容；
4. **修复**：`item` 高度改为 `WRAP_CONTENT`（左侧 4dp 竖条保持 MATCH_PARENT
   贴合行高）。真机验证 41 条全部可滚动浏览，题干完整显示。

## 五、拍照录题：裁剪 + 一律转填空（用户要求 2026-11-28）

- **裁剪**：拍完先进入裁剪模式——`CropOverlayView` 自绘浮层（四角圆点缩放、
  框内拖动平移、框外忽略），四周压暗；「✅ 确认裁剪」把浮层矩形经
  `imageMatrix` 逆映射回位图坐标裁剪；「✂️ 重新裁剪」随时回到原图重框。
  裁剪后才开放「AI 识别」（框选越准识别越准）。
- **一律转填空题**：保存时 type 固定 `fill`；AI 识别出选择题时，把正确选项的

- **优化**：位图解码（限制最长边 2400）、缩放（1600）与 JPEG 编码全部移至
  IO 线程，避免大照片 ANR。

实测发现并修复 3 个问题（versionCode 19 / 2.4.1）：

| 问题 | 根因 | 修复 |
|---|---|---|
| 拍完照后照片与裁剪框不显示（页面只剩按钮） | `enterCropMode` 未把初始 GONE 的 preview 恢复 VISIBLE，FrameLayout 高度塌成 0 | 进入裁剪模式时显式 `preview.visibility = VISIBLE` |
| AI 识别后表单只有"科目"，题干/答案/保存按钮不可见 | `buildForm()` 的 LinearLayout 忘设 `orientation=VERTICAL`（默认水平），子项横向溢出屏幕右侧 | 显式设 VERTICAL（v2.3 首版同源问题，首次装机暴露） |
| AI 识别报"Model does not exist" | `Qwen/Qwen2.5-VL-7B-Instruct` 已在硅基流动下线（PC 调 API 实测 20012） | 默认模型改 `Qwen/Qwen3-VL-8B-Instruct`（查 /v1/models + 实测 200 可用） |
