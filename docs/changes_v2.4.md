## 一、错题本"每科只显示一条"修复（根因复盘）

用户报障：错题徽章显示 41，但列表每科只显示一条。排查过程：

1. 拉取设备 `quiz_progress.preferences_pb` 逐字节解析 → **41 条数据完好**（40 个
   记录分隔符，题干完整），排除数据丢失；
2. 设备日志证明 `book=41 filtered=41`、渲染循环执行 41 次 `addView`、
   `wrap.childCount=41` → 排除数据/过滤/渲染中断；
3. **根因**：错题卡 `item` 的高度用了 `MATCH_PARENT`，而外层行容器 `row` 是
   `WRAP_CONTENT` 高——HORIZONTAL LinearLayout 在父高度未定时对 MATCH_PARENT
   高子项测量塌陷，41 行全部高度异常，仅首行可见、滚动无内容；
4. **修复**：`item` 高度改为 `WRAP_CONTENT`（左侧 4dp 竖条保持 MATCH_PARENT
   贴合行高）。真机验证 41 条全部可滚动浏览，题干完整显示。

- **优化**：位图解码（限制最长边 2400）、缩放（1600）与 JPEG 编码全部移至
  IO 线程，避免大照片 ANR。
